# Sistema de monitoramento para caixa d'agua
Este Projeto foi criado para altomatizar o abastecimento, controlar o uso de agua
e fazer teste simplis de qualidade da agua.
O usuario ele faz todo o acompanhamento e o controle por uma tela touch que mostra todas as atividades do equipamento.
## Equipamentos 
O projeto usa um controlador e sensores, tudo em uma caixa feito em impressão 3D e uma tela.
